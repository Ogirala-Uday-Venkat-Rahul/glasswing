Architectural Decision Records (ADRs)

Key design trade-offs, engineering rationale, and scalability decisions

ADR-01

Server-Sent Events (SSE) vs WebSockets

Decision: Used HTTP Server-Sent Events (SSE) for the chat generation pipeline over bi-directional WebSockets.

  • Native HTTP/2 Multiplexing: Operates over standard HTTPS with zero custom handshake overhead.
  • Built-in Disconnect Detection: Supports AbortController on client and request.is_disconnected() on FastAPI to immediately kill wasted LLM token spend.
  • Proxy & Firewall Friendly: Works reliably through corporate firewalls and edge networks without WebSocket connection drops.
ADR-02

Dynamic ReAct vs Fixed Execution DAG

Decision: Implemented a dynamic ReAct (Reason + Act) loop rather than hardcoded retrieval chains (e.g., standard RAG).

  • Autonomous Self-Correction: If an initial web query yields ambiguous results, the agent autonomously refines its search query.
  • Multi-Tool Composition: Can chain a search query ➔ fetch page content ➔ extract raw numbers ➔ run calculator tool in a single turn.
  • Strict Termination Guards: Hard limit of 8 loop iterations prevents infinite agent spins.
ADR-03

PWA Web Distribution vs Native App Stores

Decision: Distributed as an installable Progressive Web App (PWA) rather than a native Google Play / Apple app.

  • Zero Platform Fee: Avoids $25 Google Play fee and $99/yr Apple Developer tax.
  • Zero Review Friction: Fixes, prompt refinements, and UI upgrades deploy instantly via Vercel CI/CD with no app review waiting periods.
  • Regulatory Exemption: Bypasses Google Play's mandatory in-app account deletion audits and data safety filings at early-stage validation.
ADR-04

Serverless Postgres + Blob Storage

Decision: Decoupled text transcripts (Neon Postgres) from visual binary attachments (Supabase S3).

  • Zero Database Bloat: Images are uploaded directly via presigned S3 URLs, preventing multi-megabyte binary payloads from degrading Postgres queries.
  • Scale-to-Zero Cost: Neon Serverless Postgres pauses when idle, keeping database costs at $0 during inactive periods.
  • Sticky Attachments: Reuses the S3 storage key across multi-turn queries without duplicate byte uploads.
CLIENT

Frontend Architecture

Single-Page React 18 application optimized for real-time streaming and mobile ergonomics.

  • StepTimeline: Live visualization of intermediate thoughts, tool calls, and grounded domain pills.
  • Ergonomic Drawer: Responsive slide-out history panel on mobile, eliminating top scrollbars.
  • Service Worker: Instant PWA installability on desktop and mobile browsers.
ENGINE

Autonomous Agent Sandbox

Asynchronous Python tool dispatcher providing live grounding and calculative rigor.

  • Web Grounding: Tavily, Serper, and DuckDuckGo with domain citation tracking.
  • Content Extraction: Trafilatura / jusText clean DOM parsing without ads/boilerplate.
  • Mathematical Rigor: Isolated Python math parser and unit converter preventing arithmetic hallucinations.
DATA

Security & Data Integrity

Enterprise-grade authentication, session isolation, and cold-start resilience.

  • Auth: Google OAuth 2.0 with JWT stored exclusively in secure HttpOnly cookies.
  • Cold Start Badge: Automated health probe alerting users during Render free-tier cold boots (~50s).
  • Multi-tenant Isolation: All conversation operations scoped strictly to the authenticated user ID.
