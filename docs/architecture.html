ReAct Autonomous Execution Sequence

Life-cycle of a single query turn: streaming thoughts, tool dispatch, and answer grounding

sequenceDiagram autonumber actor User as User participant FE as Frontend (React + SSE) participant BE as FastAPI Backend participant LLM as LLM (Gemini / OpenRouter) participant Tool as Tool Dispatcher participant DB as Neon Postgres User->>FE: Types query & submits (with optional image) FE->>FE: Mounts AbortController & opens SSE connection FE->>BE: POST /api/chat (prompt, conversation_id, image_key) BE->>BE: Verify session cookie & initialize ReAct state loop ReAct Autonomous Reasoning Cycle BE->>LLM: Send system prompt, tool schemas & conversation history LLM-->>BE: Stream "thinking" reasoning tokens BE-->>FE: SSE event: {type: "thinking", content: "..."} FE-->>User: Live updates StepTimeline (Mote is working) alt Agent Decides to Call a Tool LLM-->>BE: Emit tool_call (e.g., web_search, fetch_url, calculator) BE-->>FE: SSE event: {type: "tool_call", tool: "web_search", args: {...}} BE->>Tool: Execute tool asynchronously Tool-->>BE: Return observation / raw results BE-->>FE: SSE event: {type: "tool_result", tool: "web_search", result: {...}} BE->>BE: Append observation to ReAct prompt context else Agent Has Final Answer LLM-->>BE: Emit final response text BE-->>FE: SSE event: {type: "final_answer", content: "..."} end end BE->>DB: Persist user prompt & final answer turn BE-->>FE: SSE event: [DONE] FE->>FE: Update Mote to 'done', enable copy button & export options
⚡

Client Tier (PWA)

Built on React 18 & Vite. Runs full-screen on mobile and desktop via service worker.
  • sw.js: Offline shell caching and PWA installation.
  • Mobile-first: Drawer slide-out for history, no awkward scrollbars.
  • Mote: Reactive winged spark mascot reflecting agent state.
🧠

ReAct Engine

Autonomous multi-step reasoning loop (Thought → Action → Observation):
web_search fetch_url calculator convert vision datetime

Streams thoughts immediately via Server-Sent Events to keep users informed.

🛡️

Data & Privacy

Serverless & zero-leak data architecture:
  • Neon Postgres: Stores user profiles and encrypted sessions.
  • Supabase S3: Presigned upload URLs for sticky image attachments.
  • Google OAuth: Secure HttpOnly JWT session token.
